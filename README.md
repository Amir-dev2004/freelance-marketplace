# پروژه پلتفرم فریلنسری (Freelance Marketplace)

**هدف پروژه:** طراحی و پیاده‌سازی یک پلتفرم فریلنسری مشابه پونیشا و Upwork. کارفرمایان پروژه ثبت می‌کنند و فریلنسرها پیشنهاد (Proposal) ارسال می‌کنند.

**اعضای تیم:**
- امیرحسین عامری
- علی مانده زاده
- علی صحاف پور

**نقش‌های اصلی:**
- **کارفرما (Client):** ثبت پروژه، بررسی پیشنهادها و انتخاب فریلنسر.
- **فریلنسر (Freelancer):** جستجوی پروژه‌ها و ارسال پیشنهاد همکاری.
- **ادمین (Admin):** مدیریت کاربران و نظارت بر سیستم.

**سیستم مدیریت پایگاه داده (DBMS):**
- PostgreSQL
